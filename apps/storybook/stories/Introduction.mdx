# Farma System

Design system de Farma para **React Native + Expo SDK 58 + Uniwind**.

Los componentes se renderizan en el navegador con `react-native-web`, igual que lo hace Expo para web,
y Uniwind aplica las clases de Tailwind. Usa la barra de herramientas para cambiar de dispositivo
(iPhone 15, iPhone SE, Pixel 8, iPad mini).

## Agregar un componente a una app

```sh
farma-system add button
```

Solo se copia el componente pedido y sus dependencias del registry; nada más de la librería.
